# Marathi transliteration rules (Layer 1 — deterministic phonetic engine)
#
# Format: <latin_key> -> <devanagari_value>   (comments start with #, blank lines ignored)
# Sections: [WORDS] exact whole-word overrides checked before compositional rules,
#           [CONSONANTS] base glyph per consonant key (glyph already carries inherent schwa),
#           [VOWELS_INDEPENDENT] used when a vowel has no preceding consonant,
#           [VOWELS_MATRA] dependent vowel sign appended to a consonant (empty = schwa, no matra)
#           [ALTERNATES] extra readings of a consonant key, one per line (a key may repeat);
#                        only readings that are dictionary words are offered
#           [LOOSE_ALTERNATES] same, for readings that stretch what was typed: they rank
#                        below a direct reading unless far more frequent
#           [VOWEL_ALTERNATES] same for vowels: <key> -> <independent glyph> <matra>
#
# Doubled letters: tt, dd, nn, ll, ss (and ddh, tth) read as a geminate first (उत्तर, शुद्ध) because
# that is how people actually type them. Their first [ALTERNATES] entry must stay the retroflex
# (ट, ड, ण, ळ, ष, ढ, ठ): it is always offered, so doubling can still force one. Doubling any other
# consonant (e.g. kk, pp) falls through to the normal consonant-then-consonant rule (क्क, प्प).

[WORDS]
# Manual overrides for words the dictionary can't resolve on its own (proper
# nouns, deliberate exceptions). The general schwa/long-vowel ambiguity (e.g.
# mala -> माला, nahi -> नाही) is now resolved by dictionary lookup instead
# (see Transliterator::transliterate's candidate-lattice search).
#
# English loanwords whose standard Marathi spelling does not follow from their
# English spelling phonetically (e.g. "january" is pronounced "jaanevaari").
# Lookup is case-insensitive.
